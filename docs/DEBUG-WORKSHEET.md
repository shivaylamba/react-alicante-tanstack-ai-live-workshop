# Failure lab worksheet

Use fixture mode in checkpoint 10 or later. Open TanStack DevTools before sending a prompt.

| Incident | Evidence to find | Recovery |
|---|---|---|
| HTTP 429 | Provider request rejected before tool execution | Disable fault and resend |
| Unknown product | Tool fails ID validation; bag unchanged | Disable fault, search again |
| Slow stream | Incremental text and active Stop control | Stop, confirm no new text, resend |
| Missing native API | Workshop lab says unavailable | Use prepared Chrome or explicitly labeled handler harness |
| Policy not found | Empty sources, not an invented citation | State limitation; clarify query |

Record prompt, observed event, component responsible, cart count before/after and recovery result. Never paste secrets into notes.
