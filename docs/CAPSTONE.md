# Capstone — 10 minutes

Pair up: shopper and observer. Use the completed checkpoint if needed. This is a transfer exercise: select a new budget or color rather than copying the default acceptance prompt. Keep all actions within the demo store; no real purchases.

1. **2 minutes — predict:** write which tools should be needed, which data must come from the catalog/policy source, and where human approval would be required. Note the initial bag count.
2. **4 minutes — try:** use either regular chat for a grounded recommendation plus an approval proposal, or the external runner for search/policy/product navigation. In regular chat deny the proposal and verify unchanged bag. With the external runner confirm no cart capability exists. Change one constraint and repeat if time permits. Do not attempt both complete journeys within this block.
3. **2 minutes — inspect:** identify one actual tool request, its result and the visible outcome. Compare your prediction to the trace. Cite the evidence mode. Native Chrome and live Nebius are required for the external path; choose regular chat otherwise and mark native acceptance unavailable.
4. **2 minutes — explain:** explain one difference between your expectation and the result, which layer owns it, and how you would investigate it. Switch speaker roles.

Score each phase 0 (no evidence), 1 (with help), 2 (independent). Maximum 8. A successful explanation may include a model failure; do not reward unsupported confidence. This is a teaching rubric, not a reliability benchmark. The aim is transferring concepts, not checking off every feature again.
