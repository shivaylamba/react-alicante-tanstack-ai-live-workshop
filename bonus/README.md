# Optional advanced lab briefs

These are guided implementation assignments after solution 12, outside the four-hour core. They are **not implemented features or tested reference solutions** in this repository. Work on a copy/branch of solution 12; check current package APIs and verify with the selected Nebius model before using it.

| Order | Lab | Prerequisite | Time |
|---|---|---|---:|
| B1 | [Persist a conversation](01-persistence.md) | Core 01–12 | 25–35 min |
| B2 | [Resume a dropped stream](02-resumable-streams.md) | B1 and run identity | 20–30 min |
| B3 | [Ask for typed preferences](03-generic-interrupts.md) | Core 07; B1 for restart recovery | 15–20 min |
| B4 | [Compact long model context](04-compaction.md) | Core 08–09 | 20–25 min |
| B5 | [Trace model and tool latency](05-opentelemetry.md) | Core 09–10 | 20–30 min |
| B6 | [Discover specialist tools and skills](06-lazy-discovery.md) | Core 03, 08–09 | 20–30 min |

Each brief provides a concrete storefront outcome, implementation steps and acceptance checks. These extensions need additional dependencies and, for durability/observability, infrastructure. Do not silently substitute these assignments for the completed core exercises.
